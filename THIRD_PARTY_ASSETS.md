# Third-party assets

Every photograph used by **AURELIA — House of Light** is licensed under the
[Pexels licence](https://www.pexels.com/license/). Each one is downloaded by
`scripts/fetch-assets.mjs`, re-encoded with Sharp and served from this
repository's own `public/images/` directory. **No image is hotlinked in the
running application**, and no image comes from Pinterest or any other
design-reference platform.

> **Disclaimer** — AURELIA is a fictional residence created for design and
> development demonstration. The photographs below are stock images of eight
> different buildings, assembled as an art-directed narrative. None of them
> depicts the project described on the site.

The same records live in machine-readable form in three places:

- `src/data/assets.ts` — the runtime source of truth, rendered by the footer and
  the `/credits` page.
- `scripts/fetch-assets.mjs` — the acquisition pipeline.
- `public/image-credits.json` — generated by the pipeline on every run.

## Other third-party material

No font files are committed to this repository. `next/font/google` downloads and
self-hosts them during the build, so the running site makes no request to a font
CDN.

The film grain, the favicon monogram and the Open Graph card layout are all
generated from code — there is no downloaded texture or icon asset.
